# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-11

### Added
- Professional repository structure with Rust workspace separation.
- Non-destructive image editing model with undo/redo capabilities.
- Checked arithmetic validations on dimensions and memory allocations.
- Asynchronous GTK background task executor with generation cancellation tags.
- Format conversions supporting PNG, JPEG, WebP, AVIF, BMP, TIFF, and GIF.
- Interactive cropping tools with pre-defined ratios and circular masking.
- Aspect ratio preservation and prevent enlargement options for resizing.
- Lossless and arbitrary rotation tools with canvas expansion and custom backgrounds.
- Pinned pre-commit configurations, GNU Makefile targets, and tmuxinator workspaces.
