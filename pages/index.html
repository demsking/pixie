Designed for focus, speed, and safety.

No bloated graphics suites. Pixie offers highly refined features optimized for daily workflows.

Interactive Crop

Free-form crop or lock to standard ratios (1:1, 16:9, 4:3, etc.). Use the built-in rule-of-thirds grid for perfectly composed results.

Privacy Protection

Every image processed automatically strips EXIF data, GPS coordinates, camera models, and history parameters to protect your location and identity.

Non-Destructive Pipeline

Edits are compiled as a sequence of mathematical operations. Adjust or revert parameters at any step, with full-res rendering happening lazily on export.

Bomb-Proof Decoding

Pixie verifies headers and dimensions prior to reading the canvas buffer, protecting your hardware from dangerous decompression bomb exploits.

Lanczos3 Interpolation

Aspect ratio locked scaling preventing enlargement. Leverages top-tier Lanczos3 filter interpolation for sharp and artifact-free resizing.

Native Libadwaita

Conforms cleanly to the GNOME Human Interface Guidelines. Perfectly adapts to desktop dark/light mode configurations and touch gestures.

Designed with deep security and privacy principles.

01

Rust Memory Safety

Built completely in Rust, Pixie prevents common memory corruption vulnerabilities (such as buffer overflows or dangling pointers) that frequently plague native C/C++ image decoders.

02

Zero Metadata Footprint

By default, Pixie strips EXIF, GPS coordinates, timestamps, editing tools, and camera details upon exporting, ensuring you never accidentally share tracking coordinates.

03

Decompression Bomb Shielding

Before allocating GPU/CPU memory for a full canvas, Pixie inspects header byte data to prevent pixel ratios from exceeding physical bounds, shielding you from memory exhaustion crashes.
